# 방송 대본 골격

> 이 파일은 대본을 만들 때 따르는 틀이다. 채워진 대본은 `output/script/YYYY-MM-DD.md` 로 나간다.
>
> 적용: `tone-guard.yaml` (사내 톤) + `style-guard.yaml` genre `broadcast`
> 참조: 개념 ID (`f-002`, `ag-2026-10-q3-results`). 아티팩트 섹션 번호를 쓰지 않는다.

---

## 만들기 전에 읽을 것

1. `ledger/broadcast_log.jsonl` — 이미 읽은 개념을 뺀다
2. `okf/index.md` — 유효 개념과 일정
3. `okf/agenda/` — 오늘 날짜, D-7, 신규 등재분
4. `okf/facts/` 중 `status: stable` 이면서 `broadcast_at` 이 없는 것
5. `profiles/<profile>.yaml` 의 `broadcast`, `eval`

`okf/archive/` 는 읽지 않는다.

## 블록 구성

앞뒤 두 블록은 매일 채워진다. 가운데 둘은 그날 상황에 따라 달라진다.

```
♪시그널
  오프닝        헤드라인 2~3개. 오늘 다룰 것만

  [2] 새 소식   어제 이후 확인된 사실            없는 날 있음
  [3] 다가올 일정  D-7 / 신규 등재                항상
  [4] 심층      EVAL deep 임계 이상일 때만       조건부
  클로징        앞으로 확인할 지표 + 출처 고지
♪시그널
```

## 블록별 틀

### 오프닝

```
♪시그널 (5초, 페이드아웃)

**[A]** ⟨0.5⟩
{헤드라인 1} ⟨0.8⟩
{헤드라인 2} ⟨1.0⟩

{한 문장으로 오늘 다룰 범위} ⟨0.6⟩
오늘 아침 경제 브리핑, {첫 꼭지}부터 짚어보겠습니다. ⟨0.5⟩

취재기자 나와 있습니다. ⟨0.3⟩

**[B]** 네. ⟨0.4⟩
```

헤드라인은 그날 실제로 다루는 것만 쓴다. 심층이 없는 날 심층용 헤드라인을 넣지 않는다.

### [1] 오늘

```
## 오늘  `SOT {agenda-id}`

**[A]**
오늘 일정부터 보겠습니다.

**[B]** ⟨0.4⟩
{일정 내용}. ⟨0.8⟩
{그 일정이 무엇을 바꾸는지 한 문장} ⟨0.5⟩
```

오늘 걸린 일정이 없으면 이렇게 연다.

```
**[B]** 오늘 예정된 공시나 발표는 없습니다. ⟨0.6⟩
```

### [2] 새 소식

```
## {소재}  `SOT {f-id} {f-id}`

**[A]**
{청취자를 대신한 질문}

**[B]** ⟨0.4⟩
{사실 1}. ⟨0.6⟩
{사실 2}. ⟨0.8⟩

[{출처} : "{원문 인용}"] ⟨0.8⟩
```

**정정일 때** — 재방송이 아니라 갱신 소식으로 연다.

```
**[B]** 어제 전해드린 {항목}이 {새 출처}로 확인되면서 내용이 바뀌었습니다. ⟨0.8⟩
{바뀐 내용}. ⟨0.6⟩
```

**신규가 없을 때** — 반복하지 않는다.

```
**[B]** 어제 이후 새로 올라온 공시나 발표는 없습니다. ⟨0.6⟩
```

이어서 `quiet_day` 항목 하나를 쓴다. `stale_preview` 가 무난하다.

```
**[B]** {n}분기 기준으로 전해드린 수치들은 {날짜} {다음 발표}에서 갱신될 예정입니다. ⟨0.5⟩
```

### [3] 다가올 일정

```
## 다가올 일정  `SOT {agenda-id}`

**[A]**
앞으로 예정된 것은 무엇이 있습니까.

**[B]** ⟨0.4⟩
{날짜}, {일정}입니다. ⟨0.6⟩
{추정 일정이면} 확정 공지는 아직 없고, 지난 패턴으로 본 시점입니다. ⟨0.5⟩
```

이미 세 번 읽은 일정은 넣지 않는다.

### [4] 심층 — 조건부

```
## {주제}  `SOT {f-id} {f-id} {f-id}`
```

배경을 다시 설명하지 않는다. 맥락이 필요하면 넘긴다.

```
**[B]** 자세한 경위는 브리핑 문서에 정리해 뒀습니다. ⟨0.5⟩
```

### 클로징

```
## 클로징

**[A]** ⟨0.6⟩
오늘 내용을 짚어보면 이렇습니다. ⟨0.8⟩

{2~3문장 요약} ⟨0.8⟩

앞으로 확인할 지표는 {n}가지입니다. ⟨0.6⟩
{지표 1}, ⟨0.4⟩
{지표 2}, ⟨0.4⟩
{지표 3}입니다. ⟨1.0⟩

다음 확인 시점은 {일정}입니다. ⟨0.8⟩

오늘 쓴 자료는 {출처 나열}입니다. ／ 모두 공개된 자료입니다. ⟨1.0⟩

아침 경제 브리핑이었습니다. ⟨0.5⟩

♪시그널 (아웃트로)
```

전망이나 조언으로 닫지 않는다. 확인할 지표까지만 쓴다.

---

## 표기

| 기호 | 뜻 |
|---|---|
| `⟨0.8⟩` | 휴지, 초 단위 |
| `／` | 짧은 끊어읽기 (100~150밀리초) |
| `♪` | 음원 자리. 대사 아님 |
| `[출처 : "인용"]` | 대괄호는 읽지 않는다. 앞뒤 400밀리초, 톤 낮춤 |
| `` `SOT f-002` `` | 개념 ID. 읽지 않는다 |

---

## 부록 (대본 뒤에 붙인다)

**A. 수치 대조표** — 낭독 표기 / 개념 ID / 원문 출처. 아티팩트가 갱신되면 이 표를 따라 고친다.

**B. 단정하지 않는 문장** — 어미를 바꾸면 사실 관계가 달라지는 문장 목록. 강조해서 읽지 않는다.

**C. 낭독 규칙** — 숫자 표기, 외래어 한글 표기, 문장당 사실 하나.

## 발행 전 점검

- [ ] `broadcast_log` 에 있는 개념을 다시 넣지 않았는가 (정정 제외)
- [ ] 일정이 세 번을 넘겨 나오지 않는가
- [ ] `tone-guard` 금지어가 남아 있지 않은가
- [ ] `style-guard` genre `broadcast` 의 S1 규칙 잔존 0건인가
- [ ] 수치가 원문과 한 글자도 다르지 않은가
- [ ] 1차자료 근거가 없는 문장에 단정 어미를 쓰지 않았는가
- [ ] 클로징이 전망·조언으로 끝나지 않는가
- [ ] SOT 참조가 개념 ID인가

통과하면 `broadcast_log.jsonl` 에 오늘 읽은 개념을 기록하고, 각 개념에 `broadcast_at` 을 찍는다.

## 영역 전환 접속사 (2026-08-12 확정)
소식 영역이 바뀔 때는 반드시 전환 접속사로 연다 — "다음은 …입니다" / "이어서 …입니다" /
"이상으로 …였습니다"(마감). 접속사 없이 영역이 바뀌면 청취자는 문맥 경계를 놓친다.
같은 영역 안의 부연은 "조금 더 들여다보면" 류로 구분한다.
